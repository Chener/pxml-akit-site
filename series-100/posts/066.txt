停止向AI许愿 · 66/100

「可能还有用」的代码堆成坟场，AI 却不敢或乱删。
口令：Dead code（死代码）——先证明无引用，再删除。

场景：utils/legacyPrice.js 没人敢动；AI 有时全删、有时碰都不碰。
对比 Ablation：消融是试验拆；Dead code 是证据齐全再删。例如：搜索0引用+测试未覆盖才进删除名单。

直接复制给 AI：
「清理 Dead code：utils/legacyPrice.js。
先交证据表：
符号 calcOld | rg 命中 0 | 测试引用 0 | 动态加载 否
我确认后再删；禁止删「看起来像」证据不足的。
每删一处：证据 + git revert 回滚方式。
确认前不动手。」

邻口令：Dead code ≠ Ablation——消融是实验性拿掉一块看影响；死代码是已证明无引用再删。
默认 harness 要么不敢删要么按「感觉」删；本口令纠正「无证据动坟场」。

先证明没用，再送走。
